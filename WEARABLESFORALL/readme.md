*Description of completed features*
 User Registration and Login: Donors and recipients can register and log in to create accounts, allowing them to interact with the platform securely.
 
-Admin Access and Management: The admin has a dedicated login and dashboard where they can manage all user accounts, including both donors and recipients, ensuring smooth operations and security.

-Donation Process for Donors: Donors can log in to their accounts to donate items, such as shoes, easily. They can enter details about the items they’re donating, which helps the platform match items with those in need.

-Admin Control Over Donations: The admin oversees the donation process, managing all donation records and keeping track of the items available, which allows for efficient distribution to recipients.


*Challenges faced and solutions applied.*
Design Accuracy and Usability:
Challenge: Ensuring the platform design was user-friendly and met the needs of both donors and recipients was difficult, particularly for first-time users. Designing the donation and request forms accurately to capture all necessary information was also a challenge.

Solution: We refined the design through feedback and prototyping, focusing on a clean layout that simplified navigation. We used consistent labeling and form fields for clarity, and included only essential information to streamline the donation and request process.
Donation and Item Request Features:

Challenge: Implementing features for donors to accurately log donated items and for recipients to request items was challenging. It was important to capture specific details like item condition, size, and quantity to match items with recipient needs.

Solution: We created structured forms with specific fields (e.g., size, item condition, pickup/drop-off preferences) to ensure all relevant information was captured. This allowed the system to better match available items with recipient requests.

SMS Notification Integration:
Challenge: Integrating SMS notifications for updates to donors and recipients required understanding API integration and implementing triggers within the system without disrupting other functionalities.
